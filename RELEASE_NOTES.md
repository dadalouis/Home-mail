### Beta 2: save button for notification settings
- The notification settings now have a **Save** button. Changes are kept on screen until you tap Save, and going back with unsaved changes asks if you want to discard them.
- **Send test notification** uses what is on screen, so you can try settings before saving them.
- From beta 1: an offline device (for example a wall tablet without local push) no longer fills the Home Assistant log with errors or holds up other devices, and notification text no longer shows links.

This is a beta. In HACS, turn on **Show beta versions** for Home-mail to get it. Restart Home Assistant after updating.
